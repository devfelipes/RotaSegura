# RotaSegura

O RotaSegura é um aplicativo web de bem-estar e segurança para entregadores de moto que trabalham com aplicativos de entrega.

Com ele, o entregador pode:

- controlar a jornada de trabalho e receber lembretes de pausa;
- acionar um SOS que envia sua localização para contatos de confiança;
- compartilhar a rota com familiares durante a jornada;
- registrar ocorrências, como acidentes, assaltos e falhas mecânicas;
- consultar o histórico das jornadas;
- acompanhar os ganhos e gastos do dia;
- trocar avisos com outros entregadores da região.

O projeto foi desenvolvido para a disciplina Processo de software - Engenharia de Software da UCSAL. Ele usa apenas HTML, CSS e JavaScript.
